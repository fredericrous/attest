# Known answers for SPEC.md, "The note": the fields of an attestation and the
# exact payload bytes a released producer signed for them. Each case was
# captured once from a real run (named in the case) and is never edited:
# a change here is a change to what every producer signs.
#
# The format is strict, and a reader refuses anything else:
#
#   case <name>       opens a case; outside one only comments (#) and blank
#                     lines may appear
#   tree <oid>        the fields, in this order: tree, gates, platform,
#   gates <names>     input (zero or more, `input <gate> <fp>`), canon (zero
#   platform <p>      or one), producer
#   input <g> <fp>
#   canon <oid>
#   producer <p>
#   payload <line>    one line of the expected payload, verbatim after
#                     "payload "; the payload is these lines, each followed
#                     by LF
#   end               closes the case
