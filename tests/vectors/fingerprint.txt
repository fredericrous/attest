# Known answers for SPEC.md, "Input fingerprints" and "Canonical tree": the
# implicit inputs every fingerprint lists, and the synthetic note keys. The
# keys were computed with `git hash-object --stdin` over the SPEC's preimage,
# in a sha1 and in a sha256 repository, independently of any implementation.
#
# The format is strict, and a reader refuses anything else:
#
#   case <name>            opens a case; outside one only comments (#) and
#                          blank lines may appear
#   implicit <tokens>      the declared paths of a gate, `?` markers removed;
#   out <path>             answered by the implicit inputs, in order
#   key <format> <gate> <fp>     K(gate, fp) in a <format> (sha1|sha256)
#   canon-key <format> <canon>   Kc(canon)   repository, answered by one
#   out <oid>                    `out` line
#   end                    closes the case

case one directory: the spec files, .gitmodules, the root .gitattributes
implicit src
out .forgejo/attest-inputs
out .github/attest-inputs
out .gitmodules
out .gitattributes
end

case every ancestor's .gitattributes, sorted and once each
implicit src/deep/x.rs x/y src/z
out .forgejo/attest-inputs
out .github/attest-inputs
out .gitmodules
out .gitattributes
out src/.gitattributes
out src/deep/.gitattributes
out x/.gitattributes
end
